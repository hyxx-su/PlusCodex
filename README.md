# PlusCodex

> Codex 사용량을 더 빠르고 간편하게 확인하세요.

PlusCodex는 **Codex의 사용량과 초기화 시간을 macOS 메뉴바에서 바로 확인할 수 있는 유틸리티**입니다.

매번 사용량을 직접 확인할 필요 없이,
메뉴바에서 현재 남은 사용량을 확인하고 필요한 시점에 알림을 받을 수 있습니다.

PlusCodex는 OpenAI의 공식 애플리케이션이 아닌 개인적으로 제작된 서드파티 유틸리티입니다.

OpenAI 및 Codex는 OpenAI의 상표 또는 서비스입니다.
